# Suç İnceleme Metodolojisi — 4 Katmanlı Kontrol Listesi

Bu dosya, bir olayın ceza hukuku açısından incelenmesinde izlenecek **sabit sırayı** tanımlar. Sıra değiştirilemez: bir üst katmanda çürüyen bir iddia için alt katman tartışılmaz.

```
① TİPİKLİK (Maddi Unsur)
        │  Fiil kanuni tanıma uyuyor mu?
        ▼
② TİPİKLİK (Manevi Unsur)
        │  Kast / taksir var mı?
        ▼
③ HUKUKA AYKIRILIK
        │  Bir hukuka uygunluk nedeni var mı?
        ▼
④ KUSURLULUK (Kınanabilirlik)
        │  Fail kınanabilir mi?
        ▼
⑤ ÖZEL GÖRÜNÜŞ BİÇİMLERİ
        │  Teşebbüs / iştirak / içtima
        ▼
   HUKUKİ SONUÇ
```

**Kural:** Her katmanda **hayır** cevabı çıkarsa bir sonraki katmana geçilmez; çıktı o noktadan itibaren sonuçlandırılır. Örneğin manevi unsur yoksa hukuka uygunluk tartışılmaz — beraat gerekçesi `CMK m. 223/2-c`'dir.

---

## ① Tipiklik — Maddi Unsur

### Kontrol Soruları
1. **Fail:** Eylemi gerçekleştiren kişi belli mi? Özel faillik gerekiyor mu (örn. kamu görevlisi gerektiren suçlar)?
2. **Mağdur / Suçun Konusu:** Korunan hukuki değer ne? Mağdur kim?
3. **Hareket:** İcrai mi ihmali mi? İhmali suçta garantörlük sıfatı var mı (TCK m. 83)?
4. **Netice:** Zarar veya tehlike gerçekleşti mi?
5. **Nedensellik:** Fiil ile netice arasında illiyet bağı var mı? Objektif isnadiyet kurulabiliyor mu?
6. **Kanunilik:** Kanun bu fiili açıkça suç sayıyor mu? (TCK m. 2 — kıyas yasağı, belirsizlik yasağı)

### Sık Yapılan Hatalar
- **Kıyas:** Kanunda olmayan bir unsuru "benzerlik" gerekçesiyle eklemek.
- **İhmali suçu gereksiz kullanmak:** TCK'da ihmali suçlar sınırlıdır; çoğu suç icrai olarak işlenir.
- **Neticeyi karıştırmak:** Bazı suçlar netice gerektirmez (sırf hareket suçları — örn. TCK m. 106 tehdit).

### Çıktı Kalıbı
```
① TİPİKLİK (MADDİ):
   Korunan değer: [ ... ]
   Fiil: [ ... ]  Konu: [ ... ]  Mağdur: [ ... ]
   Netice: [ ... ]  İlliyet: [ kuruluyor / kurulmuyor ]
   → SONUÇ: [ Tipiklik oluştu / oluşmadı — gerekçe ]
```

## ② Tipiklik — Manevi Unsur

### Ön Soru
**Suç kasten mi işlenebilir, taksirle mi, yoksa ikisi?**
Kanunda taksirli hâl açıkça düzenlenmiş mi? (TCK m. 22/1: "Taksirle işlenen fiiller, kanunun açıkça belirttiği hâllerde cezalandırılır.")

### Kast Analizi
| Unsur | Bilme | İsteme | Sonuç |
|---|---|---|---|
| Doğrudan kast (m. 21/1) | Var | Var | Temel ceza |
| Olası kast (m. 21/2) | Var (öngördü) | Kabullenme | İndirim: 1/3–1/2 |
| Bilinçli taksir (m. 22/3) | Öngördü | Önlediğine inandı | Ayrı suç, temel cezada 1/3–1/2 artırım |
| Basit taksir (m. 22/2) | Yok | Yok | Ayrı suç |

### Taksir Analizi
- **Dikkat/özen yükümlülüğü:** Failin uyması gereken somut özen kuralı ne?
- **Öngörülebilirlik:** Neticenin öngörülebilir olduğu somut olgular neler?
- **Neticenin önlenebilirliği:** Fail özen gösterirse netice önlenir miydi?

### Özel Kast / Saik
Bazı suçlar özel bir amaca bağlıdır:
- **Zimmet (TCK m. 247):** Zilyetliğin devri yok, göreve bağlı.
- **Dolandırıcılık (TCK m. 157):** Başlangıçta aldatma kastı.
- **Rüşvet (TCK m. 252):** Menfaat karşılığı görevinin yapılması.
- **Yağma (TCK m. 148):** Cebir/tehditle mal alma amacı.

### Çıktı Kalıbı
```
② TİPİKLİK (MANEVİ):
   Suçun kast/taksirle işlenebilirliği: [ ... ]
   Failin iç durumu: [ doğrudan kast / olası kast / bilinçli taksir / basit taksir ]
   Gerekçe: [ somut olgular ]
   → SONUÇ: [ Manevi unsur oluştu / oluşmadı — CMK m. 223/2-c ]
```

## ③ Hukuka Aykırılık

### Kontrol Sırası
1. **Kanun hükmünü yerine getirme (TCK m. 24/1):** Yetkili merciin emri var mı? Emir konusunda yetkili mi?
2. **Amirin emrini yerine getirme (TCK m. 24/2-4):** Bakanlar Kurulu kararı, kamu hizmeti icrası.
3. **Meşru savunma (TCK m. 25/1):**
   - Saldırı var mı? (haksız + gerçekleşen veya gerçekleşmesi muhakkak)
   - Saldırı **hâlâ devam ediyor** mu?
   - Orantılı mı? (savunma için zorunlu ölçü)
4. **Zorunluluk hâli (TCK m. 25/2):** Ağır ve muhakkak tehlike + başka çare yok + ölçülülük.
5. **Hakkın kullanılması (TCK m. 26/1):** Dava hakkı, eleştiri hakkı, basın hakkı.
6. **İlgilinin rızası (TCK m. 26/2):** Rıza açıklanmış mı, üzerinde tasarruf edilebilir bir değer mi, rıza önceden mi?

### Kritik Ayrım — Meşru Savunma vs. Haksız Tahrik
| | Meşru Savunma (m. 25) | Haksız Tahrik (m. 29) |
|---|---|---|
| Saldırı devam ediyor mu? | **Evet** | Hayır (saldırı bitmiş veya fiil ağırdan başka yöne) |
| Fiil suç mudur? | **Değil** (hukuka uygun) | Evet, ama indirilir |
| Hukuki sonuç | Beraat (CMK 223/2-d) | İndirim (1/4–3/4) |

### Çıktı Kalıbı
```
③ HUKUKA AYKIRILIK:
   Değerlendirilen nedenler: [ ... ]
   Somut olaya uyumu: [ ... ]
   → SONUÇ: [ Hukuka uygun / aykırı ]
```

## ④ Kusurluluk (Kınanabilirlik)

### Kontrol Listesi
1. **Yaş küçüklüğü (TCK m. 31):**
   - 0-12 bitmemiş: ceza sorumluluğu **yok** (güvenlik tedbiri).
   - 12-15: işlediği fiilin hukuki anlam ve sonuçlarını algılama + davranışlarını yönlendirme yeteneği gelişmişse sorumlu.
   - 15-18: sorumlu, indeimli.
2. **Akıl hastalığı (TCK m. 32):** Cezai sorumluluk kaldıran / azaltan düzeyde mi? (Adli psikiyatri raporu şart)
3. **Sağır ve dilsizlik (TCK m. 33).**
4. **Cebir, şiddet, korkutma, tehdit (TCK m. 28):** İradesiz aracı (dolaylı fail) durumu.
5. **Haksız tahrik (TCK m. 29):** Haksız fiil + hiddet/şiddetli elem + pozitif hareketle gerçekleşen fiil.
6. **Kaçınılmaz hata (TCK m. 30/4):** Anlayış/irade yanılması — failin niyeti ile gerçekleşen fiil farklı.
7. **Sınırın aşılması (TCK m. 27/2):** Mazur görülme şartları.

### Çıktı Kalıbı
```
④ KUSURLULUK:
   Değerlendirilen nedenler: [ ... ]
   → SONUÇ: [ Kusurlu / kusurlu değil — gerekçe ]
```

## ⑤ Özel Görünüş Biçimleri

### A. Teşebbüs (TCK m. 35)
**Üç unsuru doğrula:**
1. Suç işleme kararı (kasıt)
2. **Elverişli hareketlerle** doğrudan doğruya icraya başlama
3. Failin elinde olmayan nedenlerle netice gerçekleşmedi
4. **Gönüllü vazgeçme (TCK m. 36):** Fail kendi isteğiyle icradan vazgeçerse ceza verilmez; icranın tamamlanması önlenirse de vazgeçme söz konusu.

### B. İştirak (TCK m. 37-41)
| Tür | Şartlar | Sonuç |
|---|---|---|
| Müşterek faillik (m. 37/1) | Fiili birlikte gerçekleştirme + ortak irade | Her biri fail gibi |
| Dolaylı faillik (m. 37/2) | Başkası aracılığıyla suç işleme | Aracı fail sayılmaz |
| Azmettirme (m. 38) | Başkasının belirli suçu işlemesini sağlama | Azmettiren gibi |
| Yardım etme (m. 39) | Yardım fiili + asli failliğe katılmama | İndirim |

### C. İçtima
- **Bileşik suç (TCK m. 42):** Bir suçun unsuru olan fiil ayrı suç sayılmaz.
- **Zincirleme suç (TCK m. 43):** Aynı suç işleme kararı + değişik zamanlarda + aynı kişiye karşı aynı suç → tek ceza, 1/4–3/4 artırım. Şartlar birlikte değerlendirilmelidir.
- **Fikri içtima (TCK m. 44):** Tek fiil → birden fazla suç → en ağırına hükmedilir.
- **Farklı neviden fikri içtima:** Kural olarak cezaların ayrı ayrı hükmedilmesi yerine en ağıra hükmedilir.

### Çıktı Kalıbı
```
⑤ ÖZEL GÖRÜNÜŞ BİÇİMLERİ:
   Teşebbüs: [ var / yok — gerekçe ]
   İştirak: [ tek faillik / müşterek faillik / yardım / azmettirme ]
   İçtima: [ yok / zincirleme / fikri — gerekçe ]
   → SONUÇ: [ cezalandırılabilir kapsam ]
```

---

## Bağlayıcı Kurallar

1. **Sıra:** ① → ② → ③ → ④ → ⑤ → sonuç.
2. **Her "hayır" katman keser:** Bir katmanda unsur oluşmadıysa sonraki katman tartışılmaz, gerekçe orada biter.
3. **Her katman için kaynak zorunlu:** Hangi TCK maddesi, hangi doktrin dosyası, hangi karar dayanak olduğu yazılmalı.
4. **Beyan ≠ delil:** "Mahkeme bu konuda takdirini kullanır" tipi ifadeler delil yerine geçmez; her sonuç somut olguya dayanmalı.
